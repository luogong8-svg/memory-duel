# 网格消消乐 · 记忆对决

一个无需联网、无需安装依赖的翻牌记忆游戏。游戏界面、样式和逻辑都包含在 `index.html` 中。

## 在线游玩

点击 [网格消消乐 · 记忆对决](https://luogong8-svg.github.io/memory-duel/) 即可直接游玩，无需下载或启动本机服务器。可将这个链接分享给他人。

## 运行

在 GitHub 仓库中选择 **Code → Download ZIP**，解压后用浏览器打开 `index.html`。也可以通过任意静态网页服务器提供这个文件。

## 玩法与功能

- 支持人机对战和两人共用设备的双人对战。
- 可进行 4×4、6×6、8×8 三关挑战，或选择任意一关练习。
- 默认预览时间分别为 4、7、10 秒，也可设置为每关 5、10、15 秒。
- 每次翻开两张牌，配对成功后得分并继续行动，失败或超时则换人。
- 各关的回合时限分别为 10、8、6 秒；每次翻牌都会检查实际截止时间。
- 查看规则或战绩时，棋盘遮住，预览、回合计时、电脑行动和配对动画结算暂停；关闭窗口后恢复。
- 记录各关得分、翻牌次数、配对成功率、超时次数及有效用时。
- 最近 20 场已完成对局保存在当前浏览器的本地存储中，不上传至服务器。浏览器限制本地存储时，战绩仅在本次打开期间保留。

## 操作

| 操作 | 方法 |
| --- | --- |
| 翻牌 | 点击卡牌，或按 Enter / 空格 |
| 在棋盘中移动焦点 | 方向键 |
| 切换操作区域 | Tab / Shift + Tab |
| 关闭规则或战绩窗口 | 关闭按钮，或 Esc |

## 电脑策略

电脑使用带概率和容量限制的记忆配对算法，仅根据已经公开的牌面选择操作，不读取未公开的隐藏牌面。

| 难度 | 记忆容量上限 | 翻牌时记住的概率 | 利用已知配对的概率 | 出牌间隔 |
| --- | ---: | ---: | ---: | ---: |
| 轻松 | 4 张 | 45% | 52% | 760 毫秒 |
| 标准 | 8 张 | 72% | 78% | 620 毫秒 |
| 挑战 | 16 张 | 90% | 96% | 480 毫秒 |

预览阶段每 1.5 秒最多尝试记住一张随机位置的牌，尝试次数也受记忆容量限制。翻牌阶段记忆超出上限时，会忘掉最早记住的牌。

## 计分和统计

人机模式中，玩家每组得 **1 分**，电脑每组得 **0.15 分**；双人模式中，双方每组均得 **1 分**。这是当前版本保留的让分规则。

配对成功率 = 成功配对次数 ÷ 完成两张翻牌的次数。只翻一张后超时不计入这个比例，超时次数会单独记录。有效用时包含预览和动画，扣除查看规则、战绩时的暂停时间。

不同对战模式、关卡、难度和预览时长会标注在战绩中。三关挑战完成后保存整场战绩，单关练习完成后保存该关战绩。

## 技术说明

- 原生 HTML、CSS、JavaScript，无构建流程、外部字体或运行时依赖。
- 无需 API Key，不调用云端模型。
- 需要支持原生 `dialog`、`structuredClone` 和本地存储的现代浏览器。
- 已在 Chrome 中验证暂停恢复、键盘操作、超时边界、电脑记忆上限、三关流程、单关练习、战绩保存以及手机尺寸布局。
